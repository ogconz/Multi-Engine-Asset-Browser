# Changelog

## v2.2.0 - Initial public release

- Unity asset indexing, preview and GLB/FBX/PNG export.
- Unreal Engine 4 PAK indexing and UE Viewer-based extraction.
- Automatic/resumable Unreal class identification with local caching.
- Shift/Ctrl selection with filtered batch exports.
- Windows one-file executable build and automatic GitHub Releases workflow.
