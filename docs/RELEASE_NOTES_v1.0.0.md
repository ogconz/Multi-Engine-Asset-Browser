# Multi-Engine Asset Browser v1.0.0

**First public release — Windows 10/11 x64**

Download `MultiEngineAssetBrowser.exe` from the Assets section and run it directly (no Python installation required).

## A message from conz

> **A message from conz:** "Multi-Engine Asset Browser started as my idea. I decided what I wanted it to do, tested it with games, and gave feedback as it developed. I didn't personally write the code: the implementation and tooling were generated using AI. I'm sharing it as an open-source project in case other people find it useful. — conz"

## Highlights

- Explore supported Unity bundles and Unreal Engine 4 PAK archives.
- 3D mesh previews, texture previews and GLB/FBX/PNG exports.
- Shift/Ctrl multi-selection and bulk exports by asset type.
- Automatic, cached Unreal class identification with Stop/resume.
- Session: Skate Sim (UE4.27) settings in the [compatibility guide](https://github.com/ogconz/Multi-Engine-Asset-Browser/blob/main/docs/GAME_COMPATIBILITY.md).

**External tools:** UE Viewer/UModel is required for Unreal asset inspection; Blender is required for FBX. The proprietary Oodle codec is **not bundled**, and an internet connection may be required for its initial download by pyuepak. Game assets remain subject to their owners' rights.
