# Security policy

This is a community project and does not currently guarantee security fixes on a specific schedule.

Please do not publish credentials, AES keys, private game files, or other secrets in GitHub issues. To report an exploitable vulnerability privately, use GitHub's **Report a vulnerability** feature if the repository has private vulnerability reporting enabled, or contact the maintainer privately.

Only open game archives that you trust: malformed files and third-party unpackers can have bugs. Download release binaries from this repository's Releases page and verify the published SHA-256 checksums if needed.
