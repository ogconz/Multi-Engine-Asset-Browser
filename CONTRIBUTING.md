# Contributing

Thank you for helping improve Multi-Engine Asset Browser.

- Before reporting a bug, check existing issues and the [user guide](docs/USER_GUIDE.md).
- Include your Windows version, application version, Unity/Unreal engine version, and steps to reproduce. For Unreal, include the UE Viewer version and the asset class, but **do not publish AES keys**.
- Do not upload copyrighted game data, proprietary game files, or extracted third-party assets without permission.
- For changes, start with a focused issue or pull request, keep the extractors read-only, and run `python -m unittest discover -p "test_*.py" -v` before submitting.
- The maintainers may ask for anonymized diagnostics or a small, freely redistributable test fixture.

By contributing source files to this repository, you agree to release your contribution under the repository's MIT license.
